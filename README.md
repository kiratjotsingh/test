# Made by Kirat — website

Open `index.html` to view the site (keep all files in this folder structure).

## Before you publish
1. **Domain** – search & replace `YOUR-DOMAIN.com` in every file (canonical, og tags, sitemap, robots).
2. **Contact form** – create a free form at formspree.io, then in `contact.html` replace `YOUR_FORM_ID`
   in the form `action`. Until then, the form opens the visitor's email app instead.
3. **Photos** – replace the Unsplash/Pexels URLs (home + `work/*.html`) with your own optimised WebP/AVIF images.
4. **Content** – replace placeholder clients, stats, testimonials (`script.js`, section 6) and the
   case-study text in `work/*.html`.
5. **Social links** – update Instagram / Behance / LinkedIn URLs (footer + contact page).
6. **Analytics (optional)** – uncomment the snippet in `index.html`, and update `privacy.html`.

## Files
- `index.html`, `contact.html`, `privacy.html`, `work/*.html` – pages
- `styles.css`, `script.js` – shared styles and behaviour
- `made-by-kirat-combined.html` – the whole site (all pages, CSS and JS) in one self-contained file
- `favicon.svg/.ico`, `apple-touch-icon.png`, `og-image.png` – icons and social preview image
- `robots.txt`, `sitemap.xml` – SEO
